## 4. 测试方法

### 4.1 测试工具

```bash

```

### 4.2 测试流程

```
1. 打开网站
2. 执行测试场景
3. 验证结果
4. 记录问题
5. 沉淀最佳实践
```

### 4.3 验证标准

| 等级 | 标准 |
|------|------|
| ✅ 通过 | 功能正常，无错误 |
| ⚠️ 警告 | 功能可用，但有问题 |
| ❌ 失败 | 功能不可用 |

## 7. 风险和注意事项

### 7.1 风险

| 风险 | 影响 | 缓解措施 |
|------|------|----------|
| 网站反爬 | 测试失败 | 使用 API 优先 |
| 页面结构变化 | 选择器失效 | 使用通用选择器 |
| 网络超时 | 测试中断 | 重试机制 |

### 7.2 注意事项

- 优先使用 API，避免 DOM 操作
- 使用通用选择器，避免硬编码
- 记录所有问题，统一修复
- 测试完成后统一交付
